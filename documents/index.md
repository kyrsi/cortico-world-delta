# 三角洲观察文档

- [1.3.0 更新说明](releases/1.3.0.md)：配置简化、自动保存、可选昵称、保险箱适配及图鉴。

- [观察配置与保险箱适配](observation-setup.md)说明自动保存、可选昵称、按钮状态，以及两格、四格、六格保险箱的验证范围和试用步骤。

- [红色物品图鉴审核页](loot-catalog-review.html)可在浏览器直接打开。搜索「空白存储」对照同图标的两种道具，或搜索「无人机」对照四格和两格两款藏品。点击「确认」或「改名」会将审核进度保存在当前浏览器。所有收录条目都可供 Coo 查询。迁移电脑或回填扩展前，点击「导出图鉴」保留完整 JSON。
- 维护者将导出的 `red-items.json` 替换到独立扩展的 `knowledge/red-items.json`，再在扩展根目录运行 `npm run build`。构建后的审核页和扩展使用同一份数据，安装并重载新构建后，Coo 才会使用更正的名称。
- [ID 校准调试指南](identity-debug-guide.md)说明如何找到一次校准的原始截图、识别步骤和退出原因。
