# 1.3.0

## 中文

昵称改为可选输入，移除面板中的 ID 自动校准。下方个人提示可用于确认本人战斗动作；Coo 结合同帧截图判断目标，没有干员证据时不自动归为小兵。

开始观察在配置缺项时显示白色感叹号，点击进入一键配置；状态标题旁的箭头直接定位到第一个缺项，独立采集未授权时展开屏幕选择；配置齐全后显示播放。画面一键校准和快捷键校准成功后自动保存，保留截图及区域预览，提供重新截图。失败显示红色提示及手动配置入口，不覆写已有区域。

校准入口增加准备页与观察区域的布局示意，成功后显示保存标记并保留预览；可以关闭预览或进入手动配置。示意和识别使用同一套参考选区。官方宿主继续使用扩展的独立采集器。

开始／暂停观察统一使用顶部固定按钮，移除一键配置底部的重复开始按钮和配置页的「启用观察」开关。识别项目开关和选屏授权确认保留。

两格保险箱的单行、单列网格纳入物品扫描。两格、四格、六格及九格通过合成回归；各箱型的完整实战画面仍待验证。准备页只提供物品区估算，完整保险箱画面可用于测量边界。

包含 119 项红色物品图鉴、名字审核页，以及事件原始分辨率局部图查询。图鉴条目无需先审核即可查询；外部参考图片在线加载，不内嵌到仓库。

升级保留已有昵称和识别区域。校准接口成功时会立即保存；旧的显式保存接口仍保留。当前 Git 版本为 1.3.0，此次没有发布 npm 或恢复商店上架。

## English

The nickname is optional, and automatic ID calibration has been removed from the panel. Personal notifications provide evidence of the player's action. Coo checks the same-frame image for target identity; missing operator evidence does not imply an AI soldier.

Start observation shows a white exclamation while configuration is incomplete and opens Quick setup. The arrow beside the status title goes to the first missing item, or opens the display choice when World capture lacks permission. Complete configuration shows play. Successful screen and shortcut calibration saves immediately, retaining the image and region preview with a recapture option. Failures show a red status and a manual configuration shortcut without overwriting existing regions.

Calibration includes a schematic of the preparation screen and observation areas. Successful calibration keeps its saved marker and preview, with controls to close the preview or open manual settings. The guide and recognition share the same reference regions. Stock hosts continue to use the extension's standalone capture.

Observation starts and pauses from the pinned top button. The duplicate start button in Quick setup and the observation switch in Configuration have been removed. Recognition switches and display consent remain available.

Single-row and single-column grids are now included in loot scanning. Synthetic regression covers two-, four-, six- and nine-slot safe boxes. Complete real-game footage for each size remains unverified. Preparation screens provide estimated regions; full safe-box views allow boundary measurement.

Includes a 119-item red-loot catalog, a name review page and native-resolution crops from observation events. All catalog entries are available without prior review. Reference images load online and are not embedded in the repository.

Existing nicknames and calibrated regions are retained. Successful calibration requests now save immediately; the legacy explicit-save endpoint remains available. This Git version is 1.3.0; this update does not publish to npm or restore market availability.
