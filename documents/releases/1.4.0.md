# 1.4.0

## 中文

状态栏在配置缺项或需要屏幕授权时显示白色感叹号。配置缺项时点击进入一键配置；World 独立采集且配置已齐时，点击展开屏幕选择。标题旁的箭头定位到第一个缺项；独立采集尚未授权时展开屏幕选择。可以开始观察时显示播放，采集期间显示暂停。宿主查看权限不足时不显示箭头。

开始和暂停只使用顶部固定按钮。一键校准包含准备页和观察区域的布局示意，成功后保留保存标记和预览。示意与识别使用同一套参考选区。

GitHub 的 main 从 0.1.16 进入 1.4.0，并包含 1.3.0 的可选昵称、自动保存校准、图鉴和保险箱扫描。0.1.16 直接返回原尺寸画面的采集适配超过预览解码预算，不在此版本中。官方宿主使用扩展自己的采集器，预览会先缩放。已保存的昵称和识别区域保留。此次不发布 npm。

## English

The status bar shows a white exclamation while configuration is incomplete or screen permission is missing. Incomplete configuration opens Quick setup. With World capture and complete configuration, the button opens the display choice. The arrow beside the title goes to the first missing item, or opens the display choice when World capture lacks permission. Play appears once observation can start, and pause appears while capture is running. The arrow stays hidden when the host withholds viewing permission.

Observation starts and pauses from the pinned top button. One-click calibration includes a schematic of the preparation screen and observation areas. A successful calibration keeps its saved marker and preview. The schematic and recognition use the same reference regions.

GitHub main moves from 0.1.16 to 1.4.0 and includes the 1.3.0 optional nickname, automatic calibration save, catalog and safe-box scanning. The 0.1.16 adapter that returned full-size frames exceeds the preview decode budget and is not in this version. Stock hosts use the extension's own capture, which scales previews first. Saved nicknames and regions are retained. This update does not publish to npm.
